# BroadcastLens

BroadcastLens is a scalable, distributed system that enables real-time data processing and auto-scaling, optimized for large-scale network management.

BroadcastLens is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/BroadcastLens.git`
2. `cd BroadcastLens`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
